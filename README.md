## 🚀 Featured Projects

### 🤝 [CodeMate — Developer Collaboration Platform](https://github.com/rakeshbhadake/codemate)

**Tech:** React • TypeScript • Vite • Tailwind CSS • Supabase • Gemini AI

A developer community platform designed to help people **discover collaborators, showcase projects, and connect**.

- 🔎 Developer profiles, skill discovery, and **AI-assisted matching**.
- 💬 Posts, messaging, follows, project sharing, and community events.
- 🗓️ Event registrations and approval workflows.
- 🔐 Supabase authentication, PostgreSQL, storage, and Edge Functions.
- ☁️ Responsive frontend deployed on Vercel.

[![Source Code](https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/rakeshbhadake/codemate)
[![Live Demo](https://img.shields.io/badge/Live_Demo-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://connectwithcodemate.vercel.app/)

### 🥗 Nutri AI — AI-Based Food Recognition & Nutrition Tracker

**Tech:** React • Tailwind CSS • Supabase • PostgreSQL • AI Food Recognition

An AI-powered nutrition tracking app that helps users **analyze meals and monitor nutritional intake**.

- 📸 Food image recognition for calorie and nutrient analysis.
- 🔒 Email/password and Google OAuth authentication.
- 📊 Nutrition analytics dashboards and meal tracking.
- 🗄️ PostgreSQL with Row Level Security (RLS), triggers, and optimized queries.
- ☁️ Cloud storage and responsive UI.
